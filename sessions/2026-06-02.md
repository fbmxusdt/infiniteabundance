## Key Decisions Made

| Decision | Reasoning |
|----------|-----------|
| React 19 + Vite | Fast HMR, modern tooling, easy deployment |
| Tailwind CSS (no UI libs) | Full design control, custom animations |
| Custom components | Lightweight, no bloat, brand-specific |

| Scroll reveal via JS | Smooth, controllable, no extra libs |
| Sticky navbar | Modern UX, always accessible |
| 5-section structure | Clear user journey (hero → details → education → social → action) |
